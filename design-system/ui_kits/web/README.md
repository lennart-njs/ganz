# Website UI kit

Recreation of the ganz landing page (source: `ganz Richtung B.dc.html`). One page, three audiences behind a segmented switch; content fades over 200 ms.

- `Header.jsx` — wordmark, audience switch, anchor nav, small primary CTA
- `Hero.jsx` — full-bleed photo with bottom scrim, white headline, inverse + outline buttons, floating white panel
- `Sections.jsx` — Ways (3 photo cards), Safety (ink block with ruled list), Signup (white card + inline form), Footer
